How This Demonstration Works

This web application demonstrates the Two-Layer AI API Pattern:

📱 Devfest Web Client Browser / Mobile UI
↓ POST /api/chat
🤖 Firebase Genkit Flow Natural Language & Dual-Engine
↓ MCP Tool Protocol
🛠️ Model Context Protocol (MCP) Zod Schemas & Handlers
↓ HTTP / REST
🏦 Core Banking REST API Port 3001 Express Ledger

Registered MCP Tools (6):

  • get_wallet_balance - Inquires balances & profiles
  • check_transfer_status - Queries transfer ID / REF
  • check_topup_status - Queries top-up status & VAs
  • execute_transfer - Debits sender & credits recipient
  • initiate_topup - Issues virtual accounts / links
  • get_transaction_history - Returns user ledger
